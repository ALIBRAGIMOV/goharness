# goharness 0.10.0

The harness moves onto the standard library of Go 1.27, closes three more
routes to an unearned verdict, stops charging a change for the debt around
it, and ships the completion protocol as an agent skill.

The release was driven by running the gate as its users do: on the harness
itself after a large refactor, and on a real repository of 105,000 lines
with 1,396 findings of its own, into which a 300-line feature was added the
way an agent adds one. Every change below traces to something one of those
runs showed.

## What the gate judges

**Uncommitted work on the default branch is judged against HEAD.** The base
used to fall back to the parent commit whenever the merge-base with the
default branch was HEAD itself, so on a shared clone the working tree was
judged together with the last upstream commit: blamed for its suppressions,
credited for its fixes, and rejected on a file it never opened. The base is
now HEAD while there is uncommitted work and the parent commit only once
everything is committed; `change.baseOrigin` says which applied.
`TestBypassUncommittedWorkOnTheDefaultBranchDoesNotInheritTheLastCommit` is
the case, with `TestACleanTreeOnTheDefaultBranchJudgesTheLastCommit` as the
guard.

**An empty change is INCONCLUSIVE.** A diff that held nothing produced
ADMITTED with `sufficientForCompletion: true`: a completion certificate for
work the gate never saw, obtainable by verifying against the commit just
made. The `change-visible` obligation is now unproducible for an empty
change, with the remedy naming how the base is chosen. A change that touches
no Go file is still a change. `audit` is exempt, since it answers for the
repository. `TestBypassAnEmptyChangeIsNotSufficientForCompletion` is the
case, `TestADocumentationOnlyChangeIsStillAChange` the guard. A CI job on a
shallow clone that used to pass green with nothing judged now says so.

**A build constraint cannot hide a failing test.** A `//go:build` line typed
above a failing test file, or a platform suffix renamed onto it, took the
tests out of the run while the test-shape comparison still parsed the file
and saw them present. Test shapes are now measured as the build sees them,
through the same `go/build` matching the toolchain uses, so the excluded
tests are deleted tests and `GH-WEAK-003` fires.
`TestBypassABuildConstraintCannotHideAFailingTest` is the case,
`TestASatisfiedBuildConstraintKeepsATestCounted` the guard.

**Old suppressions on lines the change did not write are debt, not a
rejection.** The ungrandfatherable core blocked on any pre-existing
directive in a file the change edited. On the study repository, appending
one function to a 1,600-line file carrying three old directives rejected
the change, and the author could neither fix findings they did not write
nor except them, because the exception is a policy edit no change may
grant itself. The core now blocks on the lines the change wrote: a
directive it adds, rewrites or moves rejects the change however old it is;
one it leaves as it found it is reported beside the change, counted per
file, and rejects the next audit, where no ledger may acknowledge it.
`TestBypassARewrittenOldSuppressionStillRejects` is the case;
`TestAnOldSuppressionInAnEditedFileIsDebtNotRejection` and
`TestAnOldSuppressionTheChangeNeverOpenedDoesNotReject` are the guards.
The threat model's section 5 records the reasoning.

## The report

**The diff view is about the lines the change wrote.** It carries every
blocking row, every new or fixed row, and every row on an added line.
Pre-existing debt in an edited file is no longer listed row by row; it is
counted per file in `summary.debtInChangedFiles` and printed on one line of
the text report, with the note that an audit judges it. On the study
repository the default view went from 53 rows, 43 of them debt in two
files, to the 10 rows the change wrote.

**Mutation is discharged, not dead-ended, when there is nothing to
mutate.** A test-only change, or a change whose functions carry no branch,
comparison or error return, was INCONCLUSIVE with a remedy that asked for
branches to exist. The obligation is now discharged, `coverage.mutation`
records the targets, mutants, runs, kills, survivors, unbuilt and timed-out
counts, and the text report prints them on one line. A mutant that did not
build is still neither a kill nor a survivor.

**A broken benchmark is skipped, named and reported.** One benchmark that
panicked took every measurement of its package down with it, the failure
reason was the raw `-json` event stream, and the remedy asked for a
benchmark to be added. The benchmark that was running when the process died
is now named from the stream, skipped with `-skip`, and the package is run
again. A benchmark that fails at both revisions is `GH-PERF-003`, advisory,
and the benchmarks that run judge the change; one that ran at base and fails
at head makes the performance claim INCONCLUSIVE naming it. Error text
quotes what `go test` printed, never the JSON it was printed in.

**A tool fault names its output.** The hint for a failed benchmark run now
says what the failure is and how to reproduce it instead of asking for a
benchmark that exists.

## The agent skill

The completion protocol, the reading order of the report, what each
INCONCLUSIVE remedy means and the routes an agent must never take ship in
the binary as an agent skill in the Agent Skills format. `goharness setup`
installs it for the current user for Claude Code
(`~/.claude/skills/goharness/SKILL.md`) and Codex
(`~/.agents/skills/goharness/SKILL.md`); `goharness skill install --project`
writes the same two files into a repository; `goharness skill print` writes
it to stdout; `goharness doctor` reports both copies. A copy goharness wrote
is replaced by every newer release, and a file it did not write is left
alone unless `--force` is given. This repository commits its own project
copies, and a test keeps them identical to the shipped text.

## The standard library of Go 1.27

**`encoding/json/v2` everywhere.** Every JSON document the harness writes
(the report, the diff document, the cache manifests, the build overlay) is
encoded with `Deterministic`, multi-line and indented, without HTML escaping;
every stream it reads (`go test -json`, `go fix -json`, `go tool fix
-flags`, golangci-lint, the scanner) is decoded with `jsontext`, which
rejects duplicate names and invalid UTF-8. Struct tags were audited once:
integers and pointers use `omitzero`, strings and slices `omitempty`, and a
nil slice is always `[]`. The one visible change to the report is that `<`,
`>` and `&` are no longer written as `<` escapes; the schema stays
`goharness.report/v2`, and `goharness diff` reads a 0.9.0 document
unchanged.

**`os.Root` at every read inside a tree.** Every file a scanner judges is
opened through a root at the module, at head and in the base worktree. A
symlink that escapes the tree is not read: the run ends with an error naming
the path. `TestSymlinkOutOfTheTreeIsNotRead` and
`TestSymlinkInsideTheTreeIsRead` pin both directions.

**The runtime's goroutine-leak profile replaces the vendored goleak.** The
injected `TestMain` runs the package's tests and reads the `goroutineleak`
profile: a goroutine blocked on something nothing reachable can ever wake.
Nothing is vendored, no pin, no licence notice, and the leaked goroutine's
own stack names the site. `versions.leakCheck` replaces `versions.goleak` in
the report; on a toolchain without the profile the obligation is unproducible
with the version named.

**`log/slog` replaces zap**, and with it `go.uber.org/multierr` leaves the
module; the dependencies are `golang.org/x/tools`, `golang.org/x/sync` and
`golang.org/x/vuln`. The gate caught the cost of the migration on its own
code: `BenchmarkSchedule` rose from 169 to 217 allocations per operation
because attributes passed to `Info` are boxed, and `GH-PERF-002` rejected
the change. The scheduler logs through `LogAttrs`, and the benchmark now
reads 121.

**Smaller replacements.** `go/version` orders toolchains (a release candidate
is below its release, the bare language version below both);
`signal.NotifyContext` carries the signal into the reason an interrupted run
reports; `go/ast.ParseDirective` reads `//go:fix inline` the way the go
command does; the integration suite writes the report of a failed case into
`t.ArtifactDir()`, so a CI run with `-artifacts` ships the document;
`strings.CutLast` replaces the hand-rolled last-separator splits. Inventory
found no test waiting on the wall clock, so `testing/synctest` was not
adopted for show.

## Hygiene

The deprecated `deep` alias is gone. `--dir` is documented as what it is,
any directory inside the module to verify, since scope is never narrowed by
it. The global help fits its budget with `skill` added.

The documents were rewritten to describe the system as it is:
`docs/philosophy.md` is new and holds the bet, the three layers, the six
principles and the ideology the code holds to; `README.md`,
`docs/architecture.md`, `docs/admission-model.md`, `docs/toolchain.md`,
`docs/threat-model.md` (sections 5, 12, 14, 15 and 16) and
`docs/agent-contract.md` carry no version archaeology and no mechanism that
no longer exists.
