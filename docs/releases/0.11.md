# goharness 0.11.0

The gate now teaches the standard it enforces, cites only standards that
exist, runs eleven more defect linters, and no longer misses a goroutine leak
on a loaded machine.

## The standard, as working instructions

The agent skill carries the Go engineering standard the gate holds code to,
as a section an agent reads before it writes a line. Its sources, in order of
authority: the Go specification and standard library documentation; the Go
project's own documents (Effective Go, Go Code Review Comments, Go Test
Comments, Go Doc Comments, the FAQ, the blog, the Go Proverbs); the Google Go
Style Guide; and the Uber Go Style Guide at the pinned commit. Every line names
the rule that enforces it, or says it is a review item. The skill also gains a
read-first step (the package, its tests, `--explain-plan`) and a short
self-review to run on the diff before the gate.

`TestSkillCitesOnlyRegisteredRulesAndPrimarySources` refuses a skill that
names a rule the registry does not hold, or links anything other than those
sources. `docs/philosophy.md` states where every rule comes from: a published
Go standard, an analyzer the ecosystem already trusts, or the evidence guards.

## Eleven defect linters, advisory and experimental

asasalint, bidichk, containedctx, durationcheck, gocheckcompilerdirectives,
goprintffuncname, perfsprint, reassign, recvcheck, testableexamples and
usetesting join the strict pack. Each reports a defect, a security hazard, or
a departure from one of the standards above; none reports taste. perfsprint is
held to the Uber guide's one claim, strconv over fmt for conversions. They
enter advisory and experimental, as every rule does, and are promoted on
corpus evidence or not at all. This repository passes all of them.

## The Uber mapping cites only what the guide says

Four `UBER-*` rules anchored to headings the pinned guide does not have.
`UBER-EXI-001` claimed no analyzer existed while revive's deep-exit was
enabled; `UBER-TAG-001` named go vet instead of musttag; `UBER-GOR-001` ignored
the leak profile that enforces it; `UBER-STY-002` stated the opposite of the
guide's title. All are corrected. `UBER-PKG-001`, `UBER-NST-001`,
`UBER-IMP-001`, `UBER-PRF-001` and `UBER-PRT-001` map the guide's package-name,
nesting, import-grouping, strconv and printf-naming sections to the rules that
already enforce them.

`TestUberAnchorsNameSectionsOfThePinnedGuide` holds every anchor to the
pinned guide's headings, and every guide rule now carries the classification
of the rule that enforces it. An enforcement qualified by a check
(`GO-VET copylocks`, `GCL-revive deep-exit`) lists the guide rule under its
producer without labelling every finding that producer makes.

## A leak that had not parked is still a leak

The injected `TestMain` read the `goroutineleak` profile once, the moment the
tests returned. A goroutine that had not run yet had not parked yet, so on one
processor or a loaded runner a leaking change was admitted. The profile is now
sampled again while other goroutines remain, with pauses doubling to 128
milliseconds; a package whose goroutines have all exited still ends after one
sample. `versions.leakCheck` names the new detector, and the base-evidence
cache keys on it. Threat model section 17 has the route;
`TestBypassALeakNotYetParkedWhenTheTestsReturnIsCaught` is the case and
`TestInjectedTestMainDoesNotReportAReachableGoroutine` the guard.

## Smaller corrections

- The base-evidence cache key covers the embedded lint configuration, which
  changes without the version string; base evidence from another linter set
  no longer compares as this one's.
- The compliant patterns `goharness explain` prints: the encode helper's doc
  comment named another function, the rollback example called a `log.Error`
  the standard library does not have, and the pool examples now use
  `wg.Go` and `errgroup.SetLimit` with the wait visible.
- CI pins its actions to commit SHAs, states the test timeout a hosted macOS
  runner needs, gives the gate room with `--timeout 45m`, and falls back to
  the parent commit after a forced push.
- Comments, tests and notes that told how a defect was found now state the
  constraint the code holds instead.

## Compatibility

The report schema stays `goharness.report/v2`. `versions.leakCheck` changes
value. No fingerprint moves. New findings from the added linters are advisory
and never block.
